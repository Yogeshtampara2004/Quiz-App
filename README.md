# Quiz App

A simple and interactive **Quiz Application** where users can create quizzes, participate in them, and view results. The application allows quiz creators to manage quizzes and users to attempt quizzes in an organized and user-friendly environment.

---

## Features

### Examiner
- Create and manage quizzes
- Add and edit quiz questions
- View quizzes created by different examiners
- Track quiz participation

### Examinee
- View available quizzes
- Enroll in quizzes
- Attempt quiz questions
- Submit answers
- View results and past quiz attempts

## Installation

Clone the repository

```bash
git clone https://github.com/rahul-266/Quiz-App.git
cd Quiz-App
```

---

## Install Dependencies

### Frontend

```bash
npm install
npm start
```

### Backend

```bash
npm install
npm run dev
```

---

## Usage

1. Register a new account.
2. Login to the application.
3. Create quizzes or enroll in available quizzes.
4. Attempt quizzes and submit answers.
5. View results and quiz history.
